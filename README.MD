# Fake Job Post Detector Extension

This browser extension uses machine learning to detect fake job postings on popular job sites like LinkedIn, Indeed, and Monster.

## How to Use

1. Load the extension in Chrome or Firefox.
2. Click the extension icon when on a job posting page.
3. The extension will analyze the job post and provide a status indicating if it is fake or legitimate.

## Training the Model

To train the model, use the `train_model.py` script. The trained model will be saved as `job_detector_model.pkl`.
